# Work Smart AI

## Overview
Work Smart AI is an application that leverages artificial intelligence to enhance productivity and efficiency in various tasks. This project aims to integrate multiple services and provide a seamless user experience.

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/mukisadan2003-collab/Dan.git
   cd Dan
   ```
2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python main.py
   ```
